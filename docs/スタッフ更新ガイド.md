# スタッフ更新ガイド

## 1. 管理画面から更新する

1. https://app.pagescms.org/ を開く。
2. 招待されたGitHubアカウントでログインし、`mamiyoband_hp001`を開く。
3. 「NEWS・ライブ情報」→「追加」を押す。
4. 見出し、日付、種類、本文、画像を入力する。
5. NEWSだけなら「NEWSに表示」をON。ライブなら「LIVE INFOにも表示」もONにして、開催日と公演形態を入れる。
6. 保存後、https://mamiyoband.com/ と作成ページを確認する。

管理画面で追加した公演は、既存の手入力分より上に表示され、管理画面から追加した公演同士は開催日順に並びます。既存の掲載順は変えません。

管理画面ではデザイン部分を触れません。投稿の削除・ファイル名変更も無効にしてあります。誤掲載を消す必要がある場合は、Hermesまたは管理者へ依頼してください。

**画像の注意**：投稿とは別の画像管理画面では画像の名前変更・削除ができます。使用中の画像を消すとHPから画像が消えるため、通常は投稿画面の画像追加だけを使ってください。誤って消した場合は再操作せず、Hermesへ「Git履歴から画像を復元して」と依頼します。

保存後はGitHubでも同じ検査が自動実行されます。検査が失敗した時は完了扱いにせず、Hermesまたは管理者へ修正を依頼してください。

## 2. Hermesへ直接任せる

### 初回だけ：スタッフがHermesへ送る文

スタッフ本人が、自分のHermesへ次の文章をそのまま送ります。

> マミヨバンド公式HPの編集準備をしてください。リポジトリは https://github.com/murakamiyoshiyuki/mamiyoband_hp001 です。`authenticated-browser-workflow`を使ってGitHubの本人ログイン画面を出し、認証後にリポジトリを取得してください。`AGENTS.md`を読み、書き込み権限と公開前検査が使えることまで確認してください。この準備ではHPを変更・公開しないでください。

- このスタッフはリポジトリへ **WRITE権限** で登録済みです。
- GitHubのログイン、二段階認証、許可ボタンだけはスタッフ本人が行います。
- **パスワードや認証コードはHermesへ送らない**でください。画面へ本人が直接入力します。
- 村上さんのパスワード、トークン、秘密鍵をスタッフへ渡す必要はありません。

### HP更新を依頼する文

> マミヨバンド公式HPへ、このフライヤーの公演をNEWSとLIVE INFOの両方に追加してください。AGENTS.mdを守り、日付・曜日・会場・出演者を画像と照合し、検査、本番公開、本番表示確認まで行ってください。不明項目は推測せず「後日発表」にしてください。

Hermesはリポジトリ全体を編集・公開できます。管理画面より強い権限なので、必ずスタッフ本人のGitHubアカウントでログインします。

## 3. 権限の追加・停止

- 追加に必要: スタッフのGitHubユーザー名
- Pages CMSのGitHub App連携: リポジトリ所有者が初回のみ許可
- GitHubアカウント利用者の停止: GitHubのリポジトリ設定からスタッフを削除すると、HermesとPages CMSの書き込み権限が停止
- メールだけで招待した利用者の停止: GitHub側では止まらないため、Pages CMSの管理画面からメール招待も停止
- 停止後はGitHubの共同編集者一覧とPages CMSの招待者一覧の両方から消えたことを確認
